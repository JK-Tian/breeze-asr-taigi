# 資安與隱私防護說明 (Security and Privacy Policies)

1. **本地執行保障**: 所有影片與圖片的處理均在本地端使用系統 FFmpeg 進行，不依賴外部生成式 AI 或雲端服務。
2. **資料不外流**: 工具不會收集、儲存或上傳任何使用者影片或生成的截圖至外部伺服器。
3. **安全調用**: 確保影片軟硬體路徑的安全傳遞，避免 Command Injection 漏洞 (使用 `subprocess.run` 且避免 `shell=True`)。
4. **臨時檔案**: 處理完成後，所有生成的截圖均保存在使用者的操作目錄中，並由使用者自行管理資料生命週期。

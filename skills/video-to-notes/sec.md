# 資安與會議隱私防護政策 (Security and Privacy Policies)

## 1. 本地處理與資料隱私邊界 (Local Isolation)
- **機密防護**：視訊會議常涉及公司內部機密、未公開策略、人事或財務資訊。本技能所調用之語音辨識 (`faster-whisper` / `whisper`)、影片視覺理解與 Word 產生腳本，**必須**全部於本機環境執行，不得上傳至未授權之公開第三方雲端平台。
- **無硬編碼金鑰**：代碼與設定檔中 **MUST NOT** 寫死任何 API Key、密碼或連線憑證。敏感設定均須隔離於 `.env` 中，且 `.env` 必須排除於版本控管之外。

## 2. 暫存檔案生命週期管理 (Memory & Cache Sanitization)
- **影音暫存清理**：在完成影片視覺理解與音訊逐字稿轉換後，Agent **MUST** 調用暫存清理機制釋放暫存影音檔案，避免佔用大量硬碟空間與造成未授權讀取風險。
- **限制路徑操作**：所有產出之 Markdown 與 Word 文件僅限儲存在使用者指定的專案目錄或工作區內，嚴禁任意寫入系統重要目錄。

## 3. 輸出文件防護 (Clean Export Assurance)
- **零敏感圖片殘留**：最終產出之會議記錄 Word (`.docx`) 與 Markdown (`_notes.md`) 嚴禁夾帶未經審核的會議視訊畫面或私密頭像截圖，保證會議記錄在跨部門傳閱時的安全與純淨性。
- **套件依賴驗證**：所有 Python 外部依賴（`python-docx`, `pyyaml`, `pytest` 等）均由 `uv` 統一管理並鎖定版本，防範供應鏈攻擊與惡意套件注入。
